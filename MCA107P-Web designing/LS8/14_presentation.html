01 · The project

A neighborhood, in the making.

A responsive website for Juniper & Grain, a fictional artisan bakery built for slower mornings and local discovery.

Audience: nearby neighbors, weekend visitors, bread lovers.

02 · Plan & wireframe

A clear path from hello to the table.

  1. Hero: brand promise and featured bake.
  2. Menu, story, team, then neighbor reviews.
  3. Reservation demonstration and contact/map.
  4. Shareable footer and practical navigation.

See the complete project brief and wireframe.

03 · Design system

Warm, readable, unhurried.

  • Forest, cream, sage, and terracotta palette.
  • Editorial serif display type, system sans body type.
  • Consistent spacing tokens and a mobile-first grid.
  • Original lightweight local SVG illustrations.

Read the design rationale.

04 · Build

Semantic HTML. Flexible CSS. Small JS.

  • Semantic landmarks and accessible forms.
  • CSS Grid and Flexbox, progressive breakpoints.
  • Keyboard-operated, pauseable carousel.
  • Locally validated booking demo, no data transmission.
  • Native share action with an in-browser fallback.

05 · Test & present

Check the experience, not just the pixels.

  • Served locally over HTTP; routes and static assets smoke-tested.
  • Resize through narrow, tablet, and desktop viewports.
  • Verify keyboard focus, reduced motion, labels, and live updates.
  • Run Lighthouse in Chrome and test Firefox, Edge, and Safari before release.
